# Fonts

The type shelf for the whole estate: every font in use across Cristobal's sites, with a live-preview homepage. Self-hosted files live in `assets/fonts/`; everything else links to its canonical download page.

**Live:** https://heycristobal.com/fonts/ (once Pages is enabled)
